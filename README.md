## 📖 FontZap คืออะไร?

**FontZap** เป็นโปรแกรม Desktop บน Windows สำหรับ **ดาวน์โหลดฟ้อนหลายอันพร้อมกัน**
ไม่ต้องกดทีละอัน แค่วางลิงค์ทั้งหมด แล้วกดปุ่มเดียว — โหลดครบทุกอันภายในวินาที ⚡

---

## ✨ ฟีเจอร์

| ฟีเจอร์ | รายละเอียด |
|---------|-----------|
| 🔗 วางลิงค์หลายอัน | รองรับ URL ทีละบรรทัด ไม่จำกัดจำนวน |
| ⚡ ดาวน์โหลดพร้อมกัน | 5 threads พร้อมกัน รวดเร็วสุดๆ |
| 📊 Progress แบบ Real-time | เห็น % และความเร็ว (MB/s) ของทุกไฟล์ |
| ✅ สถานะแต่ละไฟล์ | ⏳ รอ / ⬇️ โหลด / ✅ เสร็จ / ❌ Error |
| 📁 เลือกโฟลเดอร์ | เลือกที่บันทึกได้เอง |
| 🌙 Dark Mode UI | ดีไซน์สวยงาม สไตล์ Modern |
| 📋 วาง Clipboard | กดปุ่มเดียววางลิงค์จาก Clipboard |
| 🔁 ชื่อไฟล์อัตโนมัติ | ดึงชื่อจาก URL หรือ Content-Disposition Header |

**รองรับไฟล์ทุกประเภท:** `.ttf` `.otf` `.zip` `.woff` `.woff2` และอื่นๆ

## 🚀 การติดตั้งและใช้งาน

### ความต้องการ

- **Python 3.10+** ([ดาวน์โหลด Python](https://www.python.org/downloads/))
- Windows 10/11

### ขั้นตอนที่ 1 — Clone โปรเจกต์

```bash
git clone https://github.com/porchyy/-FontZap-.git
cd -FontZap-
```

### ขั้นตอนที่ 2 — ติดตั้ง Dependencies

```bash
pip install -r requirements.txt
```

### ขั้นตอนที่ 3 — เปิดโปรแกรม

**วิธีที่ 1:** ดับเบิ้ลคลิกที่ `เปิดโปรแกรม.bat`

**วิธีที่ 2:** รันผ่าน Terminal

```bash
python font_downloader.py
```

## 📋 วิธีใช้งาน (Step by Step)

### 1️⃣ หาลิงค์ฟ้อนที่ต้องการ

ไปที่เว็บดาวน์โหลดฟ้อน แล้วคัดลอก URL ดาวน์โหลดของแต่ละฟ้อน เช่น:
- [DaFont](https://www.dafont.com)
- [Google Fonts](https://fonts.google.com)
- [Font Squirrel](https://www.fontsquirrel.com)
- หรือลิงค์ตรงจากที่ใดก็ได้

### 2️⃣ วางลิงค์ในช่องข้อความ

วางลิงค์ทีละบรรทัด หรือกดปุ่ม **📋 วาง** เพื่อวางจาก Clipboard

```
https://dl.dafont.com/dl/?f=font1
https://example.com/fonts/myfont.ttf
https://example.com/fontpack.zip
```

> 💡 บรรทัดที่ขึ้นต้นด้วย `#` จะถูกข้ามไป (ใช้เป็น comment ได้)

### 3️⃣ เลือกโฟลเดอร์บันทึก (ถ้าต้องการ)

ค่าเริ่มต้นบันทึกที่ `Downloads\Fonts` กดปุ่ม **"เปลี่ยน"** เพื่อเลือกโฟลเดอร์อื่น

### 4️⃣ กดดาวน์โหลด!

กดปุ่ม **⬇️ ดาวน์โหลดทั้งหมด** — โปรแกรมจะโหลดพร้อมกันสูงสุด **5 ไฟล์** และแสดงสถานะแบบ Real-time

### 5️⃣ รอจนเสร็จ

| ไอคอน | ความหมาย |
|-------|---------|
| ⏳ | รอดาวน์โหลด |
| ⬇️ | กำลังดาวน์โหลด |
| ✅ | เสร็จสมบูรณ์ |
| ❌ | เกิดข้อผิดพลาด |

## ⚠️ หมายเหตุ

- ลิงค์ที่ขึ้น ❌ **Error** อาจเกิดจาก:
  - ลิงค์หมดอายุหรือผิด
  - เว็บไซต์ต้องการการ Login ก่อน
  - เว็บไซต์บล็อกการดาวน์โหลดอัตโนมัติ
- ถ้าไฟล์ชื่อซ้ำ โปรแกรมจะเพิ่มตัวเลขต่อท้ายอัตโนมัติ (`font_1.ttf`, `font_2.ttf`)
